# Learner Profile

This file contains only stable, cross-domain preferences explicitly confirmed by the learner. Current exercise knowledge belongs in `LEARNING_STATE.md`.

## Confirmed learning preferences

- `[confirmed]` Use the shortest prerequisite path into a real exercise, then deepen concepts just in time.
- `[confirmed]` Teach one necessary concept at a time; avoid large prerequisite lectures.
- `[confirmed]` For unfamiliar APIs or domain concepts, first model the expert reasoning and define the essential terms. Then use: learner attempt → diagnosis → correction → learner re-articulation.
- `[confirmed]` Start from physical meaning and experimental purpose before Geant4 APIs or C++ syntax.
- `[confirmed]` Anchor explanations in the repository's real code and observed output; do not substitute generic examples when the actual source is available.
- `[confirmed]` Teach only the minimum C++ needed to understand the current Geant4 behavior.
- `[confirmed]` Explain design intent and practical experimental use, including why an abstraction exists and what common modeling error it prevents.
- `[confirmed]` Preserve causal chains and first answer the learner's narrow question before expanding context.
- `[confirmed]` Do not treat successful execution, copied wording, or scaffolded answers as understanding.
- `[confirmed]` Do not repeatedly test already demonstrated foundations unless new evidence reveals a misconception.
- `[confirmed]` When confusion appears, reduce the step size and provide progressive assistance rather than guessing what the learner knows.
- `[confirmed]` For procedures, give commands or actions in executable order and distinguish verified facts from inference.
- `[confirmed]` Keep meaningful mistakes and their corrections because they are useful retrieval cues.
- `[confirmed]` Organize durable notes for comparison and retrieval: concept chain, concise Cornell-style cues, worked evidence, common errors, and transfer rules.
- `[confirmed]` Use Traditional Chinese for learner-facing interaction; retain exact API/class names in English.
