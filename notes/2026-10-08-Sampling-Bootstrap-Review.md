## Bootstrap：本次核心量與做法

本主題的每 event 份額為 f=E_active/(E_absorber+E_active)，只在分母為正且兩項統計範圍明確時定義。母體目標量 R=σ_f/⟨f⟩；有限樣本估計使用 R_hat=s_f/mean(f)，s_f 採 N−1 分母。s_f/√N 是平均 f 的標準誤，不能直接當 R 的標準誤。

目的：同一設定重做有限數量的 events，R_hat 仍會波動；Bootstrap 用原始事件的經驗分布近似這種抽樣波動。

普通、未加權、獨立 event 的重抽流程：從 N 筆 event 有放回抽 N 筆，重算 R_hat；重複 B 次，得到 R*_1…R*_B。SE_boot(R_hat)=std(R*_1…R*_B, ddof=1)。本次示範以 2.5% 與 97.5% 分位數給近似 95% percentile 區間；不是在罕見尾端或極小 N 下保證正確覆蓋率的方法。

兩個樣本獨立：各自從自己的事件抽自己的 N，逐次算 ΔR*=R_A*−R_B*。真正配對的資料：抽整列 event 配對，兩欄共用索引；事件數相同或 eventID 相同本身不證明配對。

來源：[SciPy 官方 bootstrap 文件](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.bootstrap.html)。Codex 實際讀過重抽流程、paired、standard_error 與區間方法說明。本次分析腳本使用 NumPy 實作，沒有宣稱執行 SciPy。

### 尾端與失效條件

- 教學反例（非模擬結果）：f={0.04,0.05,0.06,0.40}。人工規定每份重抽都恰有一筆 0.40，會排除尾端被抽到 0、2、3、4 次的波動；此例會低估 SE，不能把這個方向視為所有資料的定理。
- 若原始樣本漏掉罕見尾端，普通 Bootstrap 無法憑空抽出它，R 與 SE 可能一起不可靠。實際補救要增加原始獨立事件或確認資料／模型，不能把某個事件固定入樣。
- event 若有群組／配對相關，逐筆獨立重抽可能錯估不確定性；須先核對真正的抽樣單位。
- mean(f)=0 時 R 不定義；mean(f) 接近零時比值可能很不穩定。Bootstrap 也不能排除選取、cut、幾何或物理模型造成的系統差異。

### N 與 B 的區別

N 是原始獨立事件數，B 是重抽次數。增加 N 通常提升 R／ΔR 的估計精度；增加 B 讓 SE 與區間端點的數值估计更穩定，不增加原始資料資訊。新增 events 若揭露罕見尾端，SE 不保證每一批都單調下降。

目前教學示範保留 B=500；既有 B=10,000 結果只作參考，不要求重新大量重抽。

## Cut 收斂：已到達的判斷位置

目前實際示範 ΔR=R(0.1 mm)−R(0.01 mm)=0.9198 個百分點，SE=0.5998 個百分點，近似 95% 區間=[−0.2169,+2.0858] 個百分點。包含 0，不能據此宣稱 cut 已收斂，也不能把它當成已證明沒有 cut 效應。

先定義研究上可接受的絕對差異 δ（單位為 R 的百分點；尚無已核對的 ePIC 門檻）。在區間估計適用的前提下，若整個差異區間落在 [−δ,+δ]，可支持這兩個 cut 對指定 observable 的差異小到可接受。仍需相鄰 cut／其他相關 observables 與模型檢查，不能外推成所有條件的收斂。
